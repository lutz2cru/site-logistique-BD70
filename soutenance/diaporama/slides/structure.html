[Orateur 2] Le projet est organisé en trois couches. L’utilisateur passe par son navigateur. Le site, écrit en PHP, affiche les pages et les formulaires. Derrière, la base MariaDB stocke les données et vérifie que les règles sont respectées. Dans le dépôt, on retrouve ces parties : les diagrammes dans uml, la base dans sql, le site dans www avec une page par écran, et les documents dans docs. (≈ 35 s)
