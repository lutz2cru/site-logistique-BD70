[Orateur 3] Pour concevoir la base, nous avons suivi les étapes du cours. D’abord les cas d’utilisation : qui fait quoi dans l’entrepôt. Ensuite le modèle entité-association, à droite, qui décrit les données à garder : les camions, les quais, les lots de marchandise, les emplacements. Enfin le schéma relationnel, c’est-à-dire les tables de la base, normalisées en troisième forme normale pour éviter les doublons. (≈ 35 s)
